# THE LAST UNGIVEN ANSWER

A poem about agency for make.fun agency-poem-01.

A voice is kept silent inside a room others built around it, taught to call
the cage home. Nothing outside changes — the walls and locks remain — but the
speaker places a hand on the door and opens it while trembling. The final
answer is not given in the speaker's name; it is chosen, and the choosing
itself is the agency.
